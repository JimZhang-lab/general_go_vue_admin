# 管理后台超越型演进清单（对标 Smart-Admin）

目标：不是复刻，而是在 **稳定性 / 安全性 / 易用性 / 视觉体验** 上持续超越。

参考基线（功能类别来源）：  
- Smart-Admin 开源仓库 README：<https://gitee.com/lab1024/smart-admin/blob/master/README.md>

## 一、能力矩阵（当前项目）

### 1) 已具备（可用）
- 认证与授权：登录、注册、JWT、角色/菜单权限
- 组织管理：管理员、角色、菜单、部门、岗位
- 审计日志：登录日志、操作日志
- 基础安全：验证码、统一错误处理、接口鉴权
- 基础体验：浅色动态登录/注册页、表单校验、Toast 反馈

### 2) 本轮新增（已落地）
- 登录防暴力破解：连续失败锁定 + 自动恢复
- 登录安全策略配置化：`security.loginFailedAttemptLimit`、`security.loginLockMinutes`
- 个人中心链路打通：资料字段对齐、改密字段对齐、当前用户信息兜底
- 头像上传闭环：真实上传 + 资料持久化
- 自检稳定性增强：配置路径自适应、集成测试可控开关、上传服务异常早返回

### 3) 待建设（高优先级）
- 字典管理（系统字典/枚举统一）
- 系统参数中心（动态配置、缓存刷新）
- 定时任务中心（任务编排、执行日志、重试）
- 通知中心（站内信/邮件/Webhook）
- 数据权限（按部门/角色/人员维度）
- 操作审计增强（变更前后 diff、风险级别、追踪链路）

### 4) 待建设（中优先级）
- 代码生成器（后端 CRUD + 前端页面模板）
- 多租户隔离（租户上下文、数据隔离策略）
- 可观测性升级（业务指标看板、慢接口画像）
- 安全中心（密码策略、设备会话、登录风险评分）

## 二、演进原则
- 先稳后快：任何新功能必须通过自动化构建与回归
- 安全前置：认证、鉴权、输入校验、审计日志先行
- 体验一致：新页面复用现有视觉语言和交互规范
- 可回滚：每批功能可独立发布、可独立回退

## 三、持续自检流程
每轮迭代固定执行：
1. 后端 `go test ./...`
2. 后端 `go build ./...`
3. 前端 `npm run build-only`
4. 核心场景手测：登录/注册/权限/个人中心/上传
